# 光影 Web

Vue 3 + TypeScript 单页界面，使用 hash 导航。所有业务页面调用同源 Go API；没有用于生产的假数据或成功占位。

```sh
cd web
npm ci
npm test
npm run build
```

构建同时执行 `vue-tsc --noEmit`。`dist` 是 Go `embed` 的真实发布输入，保留于源码以便直接 `go build ./cmd/server`。修改前端后应重建再编译 Go 服务。

本地开发：先启动 `127.0.0.1:3120` 的 Go 服务，再执行 `npm run dev`。Vite 的 `/api` 代理仅用于本机开发。生产无需 Node.js，所有前端资源由 Go 内嵌提供。

页面包括管理员初始化与登录、榜单及影视搜索、详情与季集选择、演员资料及参演作品、相关推荐、五站资源筛选、下载材料预览确认、订阅与自定义更新周期、追剧日历、下载任务、手动整理预览、媒体资产、任务队列、日志筛选/实时跟随/导出、连接设置及备份。

资源搜索使用分站渐进流并支持取消；预览继承搜索流程 ID，显示真实材料与需要人工复核的原因。演员作品分批加载并可按年份或热度排序；日历支持周/月视图，周期预测不会伪造集号。订阅覆盖单独显示已播缺集、未播、日期待确认、下载中和下载完成待整理。

手动整理不会自动采用 NFO 身份，需点击确认后才生成计划。计划显示实际硬链接/复制方式、目标路径、空间预估和冲突；媒体资产移除先预览文件范围。失败任务通知可标记已读并跳转任务，任务详情保留候选筛选原因与关联日志入口。

下载任务可读取实际文件并人工纠错，单独预览关联整理计划；更换作品、季集或目标目录需要明确确认订阅暂停与占位调整。搜索会载入该作品订阅中已确认的集号映射，并随搜索及下载预览提交。旧库无 NFO 文件通过候选列表人工选择官方影视和季集，仅登记外部索引，不改视频与旁车；已移除资产可明确解除重新获取排除。

浏览器图片统一使用带会话认证的同源图片 API，无需客户端直接连接 TMDB；允许的图片尺寸和相对路径均受限制。

日志查询支持游标继续加载、当前筛选导出、实时流缺口提示与写入健康。日志保留天数/总容量/单文件大小及指定模块或站点的临时 DEBUG 独立保存。前端诊断只发送固定页面类型、错误分类及静态概述，不上传异常原文、参数、表单或堆栈；单元测试验证该边界。

凭据从服务端返回时为空，表单只显示保存状态。填写的新凭据只在当前页面内存中保留，保存后清空；不写入浏览器存储。下载地址和站点 passkey 不进入资源列表。API 错误显示服务端信息与关联请求 ID。

依赖锁定于 package-lock.json。TypeScript 7.0.2 与当前 vue-tsc 3.3.13 实测不兼容（其 `typescript/lib/tsc` 路径不再导出），因此使用兼容稳定版 6.0.3，并保持实际类型检查。

测试命令使用 Node 自带测试运行器及 TypeScript 转换（开发环境 Node 25）；发布后的 Go 服务无需 Node。
