SiteStatistic 核心站内消息链：开发里程碑，2026-10-22

范围
本轮实现核心采集完成后的未读消息及低分享率提醒真实链路，并与分身统计摘要分开。一次核心采集仅产生一组核心消息，各 SiteStatistic 分身仍保留独立配置、调度、历史和摘要。SystemError / SSE 与通知铃界面仍属后续同插件阶段，本轮不宣称 SiteStatistic 整插件完成，不增加正式生产迁移 7/23 数量。

原版证据与行为
MoviePilot 1528176beacc0f9f8d8d9cbf1adf048b0da67b5c 的 app/chain/site.py，SHA256 06358a8fd070d46ab254015a2f8c7a34f07c35dd240bd2b3fef38cbf219252fa，与已冻结安装来源指纹一致。离线 AST oracle 共 63 个标注案例；生成器要求显式来源文件且校验该 SHA，不下载或运行完整原程序，不成为生产 Python 依赖。MessageOper / schema 的公开来源和 stub 边界见 testdata/plugins/site-message-oracle/README.txt。完整已安装 IndexerModule 尚无精确源码，不能以公开版本替代宣称逐字一致。

顺序为采集、账户事实与单站刷新事件、逐条未读通知、分享率提醒、返回。后条构造或通知失败保留先前已提交事实/通知，停止后条、分享率及批次星号事件。原始 JSON 行保留 null、标量、字典顺序以及延迟逐条解包；第四项为可选 Source，其后忽略。truthy Source 仅按真实通知历史全局去重，不把预留当已发送；无 Source 的重复消息独立保留。核心站内链接使用站点域名，不混成全局 AppDomain 插件摘要链接。

持久化、恢复和权限
密封采集准入及原始身份/输入证明阻止结果未知时重新采集或阅读。原始 origin 与当前 job lease 分离；每个新副作用重新核对当前 API / 站点执行授权。旧持久摘要、空业务和畸形版本保留冷恢复/拒绝测试，不自动升级成可发送新任务。
已完成 ordinal 的延迟通知不依赖后续 worker 的 retry_wait / waiting_paused / failed 状态；显式取消及当前撤权仍阻止发送。确定未发送的撤权收据允许后续 FIFO 推进，未知发送状态保持阻断，不自动重发。真实 history 执行证明与历史同事务提交；用户删除 UI 历史不破坏原已完成事实，有记录但被篡改仍拒绝。
本地 RequestGuard 才可产生私有确定撤权标记，SITE_CHANGED / PLUGIN_API_AUTH_REVOKED 原码保留。即使随后恢复授权，已观察的拒绝也不会变成成功。provider / transport / SQL 的同名错误没有此权限，仍为未知。aborted 不声称此前从未发生网络，只表示已知本地拒绝、未提交当前事实，不重新采集。

安全与明确限制
仅本任务合成凭据及 owned HTTP fixture，clean runner 清除真实环境集成/代理/账户来源；这不是操作系统级断网。新增测试 helper 把通知 TMDB 夹具限定为自建目标，无公共 fallback；普通完成夹具以自建 trap 代替非 owned 失效端口，任何请求仍失败。未触碰真实账户/调度/部署，未重跑曾被拒的实网 runner。
私密 stdin 本轮未复验。仓库原 40 个二进制缺件未删除、伪造或替换，当前列明门禁真实执行通过，不扩展成源码全量完整声明。Go 对孤立 UTF-16 surrogate 的行为未声称 Python 精确一致。原始 parser oracle 为三字段，第四 Source 合成 DTO 覆盖不声称来自真实私有站点响应。后续 SystemError 原生 Go 诊断和 SSE 是尚未验收开发阶段。
