# 插件安装统计：停止主动上报

## 当前约定

2026-11-04，用户明确要求“不上报给这个地址”，并进一步表示“也可以不上报”。此要求取代此前“仅剥离仓库 URL 查询参数后继续上报”的选择。

应用不再主动上传插件安装统计：

- 安装和更新后的单插件统计不发送。
- 启动时的已安装插件列表不发送，重启也不补报。
- 旧配置中的分享开关为 true、旧统计中心地址和已有上报回执都不会重新启用上传。
- 两个原生命周期上报入口保留为空操作，不读取配置、安装清单或 UID，不访问 HTTP，不新增或改写上报回执。已有回执不删除。
- 不再有插件安装 ID、仓库地址或已安装列表通过这两个入口发往 `movie-pilot.org` 或其他统计中心。

这些改动适用于采用本实现的新构建。本次不部署，不改变仍在运行的旧版本服务。

安装、仓库同步、更新和制品下载保持原有行为，使用完整仓库及制品 URL，不套用旧的统计 URL 清理函数。旧清理函数仅保留兼容测试，不再用于构造上报请求。

## 查询和评分

本次没有关闭用户自配的统计/评分服务：统计查询以及用户主动执行的评分读取、提交仍走原有客户端。系统设置的开关因此改名为“读取插件安装统计”，并明确提示“本应用不主动上报插件安装数据”。既有字段 `plugin_statistic_share` 保留，现只影响统计查询。

默认服务地址仍为 `https://movie-pilot.org`；显示市场统计或使用评分功能时仍可能访问该地址，并使用既有 UID 和 User-Agent。这不是“完全不访问该域名”的改动，也不能称完全匿名。用户设置的其他服务地址没有被清空或禁用；地址留空仍会停用中心查询和评分。

## 验收边界

历史原版对照、统计显示、协议和评分验收继续保留。原版自动上报和成功回执行为现为用户明确要求取消的功能，不再以原版会 POST 为当前期望，也不把旧 PASS 当作本轮“不上报”的证明。

本轮只验受影响的无上报出口、实际安装、重复安装、下载 URL 参数、启动/冷重启、旧回执保留、统计读取、评分读写，以及设置组件和前端构建。使用合成数据和本地受控服务，不向实际统计中心发送数据，不部署或合并 main。完整命令、结果和独立审查记录随本项证据交付。

此前普通 URL 查询参数原行为的旧单案原始日志仍缺失；11-02 的恢复后单案是独立新执行，不冒称找回旧日志。本轮没有重采该案例，也不需要用该差异推导上报授权。
