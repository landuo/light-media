# v0.3.14 多站连接测试

站点管理允许连续点击不同卡片的连接测试按钮，各站独立显示排队、测试中及结果。顶部「测试连接」会测试点击时当前筛选列表中的站点；筛选或搜索变化不改变本批目标。停用站点可显式测试，测试不会将其启用。

单站与批量共用最多 3 个在途请求，同一站点未完成时复用原请求。单站业务失败或网络失败不阻断其他站点。批量显示完成数量、成功和失败数量，失败卡片显示原因。排队和测试状态不会让卡片立即退出原连接状态筛选，完成后再按实际结果筛选。

沿用后端逐站刷新接口。由于响应包含整表快照，并发完成时仅合并对应站点，避免其他旧行覆盖已完成结果；队列结束后统一重新读取一次站点列表。离开页面停止派发未开始任务，已发请求返回后不更新页面或弹提示。

原版依据：MoviePilot-Frontend 的 `SiteCard.vue` 每张卡片独立测试，原版卡片列表没有批量测试入口；本次批量入口按用户提出的多站测试需求增加。

验证：

- 前端全部 97 项测试通过，其中站点管理 14 项；新增 4 项覆盖并发上限、混合失败与筛选快照、单站/批量去重、乱序整表响应与最终读取失败，以及卸载停止派发。
- 类型检查、生产构建、格式检查、Linux amd64 纯 Go 编译通过；凭据扫描核对 18 个已知值，无匹配。
- 浏览器使用无生产凭据的 7 站合成实例：先点击两个单站，再启动批量，共 7 个不同站点请求，并发峰值 3，全部完成，模拟成功 5、失败 2。响应刻意包含其他站点的过时行。此结果验证交互与调度，不代表实际 PT 站点认证结果。
- 1440×1000 桌面确认状态和汇总可见；390×844 手机工具栏采用两列，筛选宽 166.5px，可完整显示当前状态。
