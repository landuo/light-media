# v0.3.1：文件管理、整理历史与下载管理

依据用户 2026-10-15 的反馈，对照本机 MoviePilot v2 前后端源码修正这三个页面。本记录取代 v0.3.0 中下载范围、手动整理和整理历史的操作说明，不代表原版全部高级功能已复制。

## 原版依据与本次操作

| 范围 | 原版依据 | 当前操作 |
| --- | --- | --- |
| 下载任务范围 | `DownloadChain.downloading`、qBittorrent `downloading` 过滤及 Transmission 状态 3/4 | 只显示仍属下载范围、带本应用标签或本应用下载记录的任务；不接管旧 MoviePilot 标签或全部做种任务 |
| 下载卡片 | `DownloadingListView.vue` 与下载卡片 | 下载器切换、封面与影视信息、原文件名、大小、速率、剩余时间、进度、暂停/开始/删除；无手动整理入口。原版删除包含下载数据，按钮提示明确此含义 |
| 文件管理 | `FileBrowserView.vue` | 本地存储、路径面包屑、目录树、排序、上级、新建目录、通配符与大小写过滤、刷新、选择模式；单文件详情、下载、识别、刮削、重命名、整理与删除 |
| 手动整理 | `ReorganizeDialog.vue` | 文件管理和整理历史共用弹窗。默认自动方式、目录与身份；支持显式类型/TMDB、季号、集数范围/定位/偏移、Part、大小过滤、重命名、刮削和类型子目录；预览可选，直接立即整理或排队 |
| 整理历史 | `TransferHistoryView.vue` | 搜索/成功失败筛选、通配符、分页、分组、选择、同页重新整理。删除窗口提供仅删除记录、删除源文件、删除目标文件、全部删除四种动作 |
| 整理队列 | `TransferQueueDialog.vue` | 按影视合并展示文件任务、实际状态与完成数；取消仅作用于选中的可取消文件，不伪造完成 |
| 媒体库内容 | 用户明确要求移除 | 导航中不提供媒体库内容页；旧 `library`/`assets` 前端地址转到文件管理。后台目录与文件归属索引仍服务于整理、重复检查和飞牛对账 |

自动化任务仍按已保存的目录规则、订阅和下载状态工作。本轮不重新配置下载器、飞牛库或旧 MoviePilot 服务。

## Joker 2024 失败修复

实际文件名为 `Joker.Folie.a.Deux.2024.2160p.AMZN.WEB-DL.H265.HDR.DDP5.1-ADWeb.mkv`。v0.3.0 文件扫描返回 `ambiguous_movie_suffix_or_title`，直接整理在创建计划前被拒绝，所以历史中没有对应记录。

修正电影文件名中的平台、音频参数和发布组尾缀解析，并对原名比较进行标点、大小写和拉丁音调归一化。官方查询唯一匹配 TMDB 889737《小丑2：双重妄想》（2024），原名 `Joker: Folie à Deux`。多义结果仍要求人工指定，不凭相似标题写入。

直接提交时的准备失败现在会留下真实的失败历史和原因；仅预览失败不产生整理历史。立即整理等待持久任务完成，失败时保留弹窗和错误；排队仅在实际提交后提示受理。两者使用同一套校验和后台写入流程。

## 重新整理与文件保护

重新整理的原资产归属只从服务端历史记录取得，客户端不能自报资产所有权。执行前核对原资产及自管文件快照；新目标发布成功后才转移索引占位，并安排可恢复的旧自管文件清理。目标冲突或文件被外部修改时保留原结果。相同目标可复用视频并按本次选择重新刮削；原下载源缺失时可核验旧目标后作为整理来源。

删除与重整保持文件归属、当前快照、共享旁车和做种保护。不会为了覆盖冲突而删除不属于本应用的目标文件。普通手动整理可以选择库内来源，最终文件目标仍须通过重叠与冲突校验；自动监听继续使用原有源/目标边界。
