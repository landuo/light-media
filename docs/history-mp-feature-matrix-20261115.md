## 7. 汇总与后续优先级

- 统计：共 77 项，**✅ 62、🟡 8、❌ 8、⚪ 2**（两行同时标了两种状态，分别计入）。
- 未实现（❌）：整理屏蔽词、移动后删种、挂载盘空目录清理、AI 单条重整、AI 批量重整、AI 重整按钮与进度、NAS/云盘真实写入验证。
- 有限制（🟡）：远端存储手动目标、旧版分来源 ID、下载器/hash 历史字段、外部模块改写既有文件、Linux 权限/时间戳运行验证、移动端逐页回归。
- 产品约定（⚪）：类型一级目录、MP delete+insert 换历史 ID。

建议顺序：1) `TransferExcludeWords`（设置+转移过滤+删种条件）；2) 移动后删种策略（保留现有做种安全开关）；3) AI 重整（单/批 + 进度，需先确认是否引入 AI Agent 范围）；4) 空目录清理；5) 历史下载器/hash 字段与旧版来源 ID 兼容；6) 远端存储手动目标；7) 真实 NAS/Linux/移动端验收。
