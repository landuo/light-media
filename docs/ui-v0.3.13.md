# v0.3.13 站点编辑弹窗

针对用户截图中三个开关纵向居中、留白分散和弹窗滚动的反馈，调整站点编辑页。

- 原选项卡片改为连续设置行：名称、必要说明在左，原生可聚焦开关在右；未接入的代理与浏览器功能继续禁用并就地标明。
- 频率开关保留原 v-model 和保存语义，开启后展开三项设置；桌面三列、手机单列。关闭后仍由原保存逻辑提交三个零值。
- 编辑弹窗独立采用固定标题、可滚动正文、固定操作区；错误信息固定在操作区上方，避免被正文滚动隐藏。删除与统计弹窗未使用新布局。
- 收紧间距、Cookie 文本框和提示文字；缺省超时显示 0（默认值），缺省下载器显示“默认”，而非空白。

验证：20 项站点/导入相关测试、类型检查、生产构建、Linux amd64 纯 Go 编译通过；秘密扫描核对 18 个凭据值无匹配。只读合成实例在 1440×1000 下关闭频率时正文 clientHeight/scrollHeight 均 693、scrollTop=0、完整弹窗 842px；390×844 手机无横向溢出，标题顶部 11、操作区底部 833，展开频率为单列。模拟保存返回 405 时，错误和操作按钮均仍可见。合成实例没有生产凭据，没有实际修改站点或媒体数据。

同时核验现有部署缓存：内外网 HTML 一致且 `Cache-Control: no-cache`，哈希资源使用 immutable；没有 Service Worker。用户截图中的白侧栏/紫色属于已打开页面保留的旧前端，需要整页刷新才加载新版，单纯切换 SPA 菜单不会更新代码。
