# 插件彻底卸载 2.2 交付记录

v0.4.1 交付记录（2026-10-20）：该版本已部署，插件彻底卸载 2.2 已正式迁移，保持原停用状态；实际冷启动及生产表单已核对。该次发布时实际为 2/23；最新总体进度见主迁移清单。实际导入收据见 [正式迁移收据](plugin-uninstall-deployment.json)。

原安装的两个清理开关均为 true，plugin_ids 为空，get_state 恒为 false；运行数据和插件数据文件均为 0。专用迁移程序按原字节校验来源，仅通过应用密文存储导入配置和收据，保持停用，不排任务、不执行卸载；重复导入同一来源只返回同一收据。只读试运行核对数据库内容、大小与修改时间，运行中的实例会拒绝导入。

实现保留原版两个开关、多选插件及提示，按原顺序逐项停止服务、移除注册与包、选删配置和运行数据，最后分别保存已安装列表和清空自身选择。Go 插件共用可执行文件，因此删除逻辑插件注册及其私有资源，不删除共享主程序。某个后续步骤失败时，先前已完成的移除不会回滚；失去提交回复且证据不足时停止恢复，不自动重放到重装后的新实例。

已核对原版安装接口的顺序和 SystemConfig 缓存行为：新装、重装只在原安装列表缺少 ID 时追加，升级和配置变化不重排。清理失败后，相同的 warm 缓存值会跳过数据库写入；冷启动仍读取旧 durable 列表，新的显式执行可以再次遍历已移除 ID，已有 tombstone 不增加代际。该全局来源状态与本地可执行注册分别加密保存，已用原 AST 连续执行参考、真实 HTTP→工作器→SQLite 以及同一最终二进制页面操作验证。

合并后 870 项应用测试通过（含子测试 1860），5 项既有外部环境检查明确跳过；72 项相关竞态测试通过（含子测试 168），vet 和 macOS/Linux 纯 Go 构建通过。前端 192 个输入与上一轮 157 项实际前端测试对应版本逐字节相同，本轮未重复运行。最终专用工具在独占应用目录完成初始化、只读试运行、正式导入、重复收据、冷启动和运行锁拒绝，未操作旧系统或用户插件。

原系统 UserInstalledPlugins 的完整顺序、文件夹及布局仍待后续独立迁移；本次仅保留新服务已有本地顺序，不擅自重排用户的新操作。其余插件的功能、配置、数据和实际迁移仍继续逐项核对。代码与验证输入见 [验证报告](plugin-uninstall-verification.json)；正式导入的运行收据、密文校验、0 卸载任务及实际页面截图另见上述迁移收据。
