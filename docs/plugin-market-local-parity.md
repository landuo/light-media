# 插件市场与本地仓库校正（2026-10-25）

本批修正 G11 的来源与更新选择，并实现 G12 的受管 Go 本地制品路径。不能据此将插件模块、G11、G12 或 G27 整组记为完成；[28 组验收基线](plugin-framework-acceptance-baseline.md)仍然适用。

## 固定原源

以 MoviePilot `8a83efeacd3e26b82be495e17d50146e31c96a60` 为准：

- `app/core/plugin.py:1558 process_plugins_list`：同 ID 保留最高版本，同版本按已配置远程来源顺序，远程优先本地；`app/utils/string.py:808 compare_version` 使用原版字段比较，不替换为 SemVer。
- `app/helper/plugin.py:487 get_plugins`、`app/core/cache.py:1125 cached`：每来源 1800 秒、128 条缓存，默认跳过失败的 `None`；强制刷新通过 `app/helper/plugin.py:385 __append_cache_buster` 增加 `_refresh`。
- `app/helper/plugin.py:80–137,209–376`：`local://ID?path=...` 来源、已配置目录、候选扫描及版本选择。安装来源不是任意本地文件读取授权。
- `app/core/plugin.py:289–427,580–620`：`DEV || PLUGIN_AUTO_RELOAD` 控制监控，已安装插件变化后同步运行副本并重载，未安装插件不自动安装；`app/core/config.py:446–448` 的自动重载默认关闭。
- MoviePilot-Frontend `PluginCardListView.vue` 的 `fetchUninstalledPlugins`：将已安装插件的更新来源转到已安装卡片，市场只保留未安装候选。

`testdata/standard-market/generate_oracle.py` 只在开发时从固定 Git blob 提取并执行原方法，生成 17 组版本比较、9 组来源合并结果。应用与 Go 测试仅读取生成 JSON，没有 Python 运行依赖。

## 当前行为

1. 多个远程仓库与本地目录合并后，使用原版版本排序与来源优先级；安装卡片不再将较旧版本标为更新，分身不自动使用其来源主插件的升级入口。HTTP 默认仍返回卡片数组，前端使用 `?details=true` 读取逐来源结果。
2. 显式刷新绕过本机缓存并带远程刷新参数。失败的首次读取不缓存；强制刷新失败时，仍在 TTL 内的成功元数据可以保留，但返回 `stale=true` 和明确失败提示。前端显示失败仓库及重试入口，不将残留信息标成刚读取成功。
3. 「插件市场设置」可配置本地服务器目录和默认关闭的自动重载。目录规范化后保存，每个目录包含一个 `go-plugins.v1.json` 单插件索引，制品 URL 必须是目录内相对路径。安装请求只接受与当前配置完全相同的规范目录；拒绝越界路径、目录替代、符号链接索引/制品和任意 `file://`。使用 Go `os.Root` 约束文件打开，原有大小、摘要、主机契约和包文件校验继续生效。
4. 实际安装和更新生成独立受管代码副本及 `local://` 来源收据。分身复制自身代码和来源，移除本地来源后已安装主插件/分身仍可读取自己的代码；来源收据不授予后续安装权限。
5. 自动重载每秒检查索引及所选制品的大小/修改时间。首次启用或修改目录配置只建立基线；后续变化只同步已安装主实例，不自动安装已卸载插件、不改写分身。非强制获取失败沿用制品恢复流程；同一失败发布不会每秒重复重试，发布内容再次变化后重试。初始化失败单独记录失败，不显示重载成功。停机封闭后台接入后不再允许新重载。

## 验证分层

- 固定原方法 oracle：17 比较 + 9 来源合并，包含本地/远程同版本优先级。
- 真实 Go worker/本地 HTTP：独立 1.0、2.0 制品实际启动，多源更新、TTL/强制刷新、失败/旧缓存提示、本地安装、更新、分身独立性、损坏发布恢复、取消监控、卸载后不重装、停机接入关闭和设置保存。文件变化由生产扫描方法驱动；没有将其当作监控循环长期运行验证。使用测试数据目录；没有操作生产服务或原 MoviePilot。
- 制品包安全测试：本地配置权限、来源身份、路径/符号链接、损坏/缺失包恢复、独立分身及来源移除后的代码读取。普通制品测试包含惰性字节样本，不将其标成真实插件业务。
- 真实 SFC 编译/执行测试：更新确认发送当前 `/plugins/install` 参数、严格 `success=true`、旧迁移/恢复动作不会写入、分身设置的实例身份、来源刷新及设置清空。退役测试被改写为当前公共入口断言，并保留旧动作不可执行的负向覆盖。

本批最终计数和命令见 [验证摘要](validation/plugin-market-local-parity.json)。首次 macOS 默认临时目录经过 `/var` 符号链接，命中既有安全检查；改用工作树内规范 `TMPDIR` 后运行，没有放宽生产校验。保留了关闭接入后继续卸载造成 `APP_STOPPING` 的测试编排失败记录，随后将停机检查拆为独立场景；另保留“清空最后本地目录”修前失败证明。

## 尚存差异

- G12 为 Go 制品适配：不是 Python `package.json`/`plugins.v2` 源码加载，不运行 pip；每个目录仍是一个 Go 插件索引。源码修改须先重新构建并发布正确索引/摘要，原版任意 `.py` 编辑、运行目录源码监控及联邦构建目录实时同步并未逐项移植。轮询使用索引内容和制品大小/mtime，同大小、同 mtime 的外部字节替换不构成已验证的监控事件。
- G11 的完整备份/恢复 UI、所有历史发行版选择仍需继续核对；本批实际使用已有制品获取/恢复机制，没有新造“已恢复成功”的入口。
- G13 的启动修复/更新同步由同批独立实现及证据覆盖，不由本地监控测试代替。
- G27 的原版 GitHub 历史、安装统计、评分、遥测及对应 provider 尚未在本批实现；不填充模拟数据。
- 23 个既有 Python 插件的业务重写和真实外部 provider 联调不属于本批证据，不能将框架样例或 HTTP 200 当作原插件业务验收。
