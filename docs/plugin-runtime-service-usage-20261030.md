## 复现

Go 生产不依赖 Python。Python 脚本仅用于隔离运行固定原程序生成 oracle。源重放需已有独占依赖和自有 HTTP peer，不安装/改写生产依赖。目标使用原工具链、共享缓存和串行大构建，`GOPROXY=off GOSUMDB=off GOFLAGS='-mod=readonly -buildvcs=false'`。

以本片 `test-results-normal.json` / `test-results-race.json` 保存的精确测试根和 fixture 参数为准；不要用宽泛正则或 `go test ./...` 重启旧被拒的权限、inode、TLS/CA/CONNECT 测试。浏览器只走官方 `sites-preview` 与自有测试实例。UI 专用 Go worker 源保存在 `testdata/service-ui-20261030/`；其真实处理器与已验普通 fixture 逐字一致。
