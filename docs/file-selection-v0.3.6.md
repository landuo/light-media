# v0.3.6：文件勾选与目的目录选择

按用户「文件列表勾选框和文件／目录选择窗口都不顺手」的反馈，对照 MoviePilot-Frontend 的 FileList.vue 与 PathInput.vue 调整。

## 变化

- 文件勾选由 18×18 改为 22×22，外层点击区域 40×40。点击文件名或整行仍切换选择，点击勾选区域只切换一次。
- 多选和退出多选采用不同图标。刷新或切换排序后保留仍存在的有效选择，离开当前目录清空；虚拟挂载父目录只导航，不进入批量操作。
- 手动整理目的路径旁新增目录树按钮。打开不改变输入，按当前路径展开；展开按钮仅浏览，点击真实目录即时回填，并可继续进入子目录。
- 保留直接输入、清空、自动和配置目录建议；回填不改变目的存储、整理方式、按类型分类或刮削。
- 目录读取错误可重试；关闭后旧请求不能覆盖重新打开的状态。Esc 关闭并返回按钮焦点，Tab 在目录弹层内循环。

原版文件列表没有全选或 Shift/Ctrl 范围选择，本次未另加这些操作。原版整理目标本身为可输入 combobox，本次保留这一操作，目录树参照其 PathInput 的浏览方式。
