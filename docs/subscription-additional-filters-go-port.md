## 已接通的行为

`internal/torrentfilter` 保留原匹配顺序：包含、排除、质量、分辨率、特效、体积。前两项匹配“原标题 + 原副标题 + 标签 + 促销文字”，后三项只匹配原标题；正则忽略大小写。后续条件惰性求值，早期不匹配不会访问后面的错误表达式。缺少副标题在纯内核参考中按 Python 的 `None` 文本处理；App 对新采集资源读取 `SourceSubtitle`，无该事实的旧记录继续回退现有 `Subtitle`，不能据此声称已重建旧记录中所有 null/空字符串差别。

促销文字使用原上传/下载系数映射，包括普通、免费、2X/4X、百分比和未知。体积采用 MiB，两端包含等号；单独数值、前置空格等走原 unknown 分支，不自行补成最小体积。Python 允许的 Unicode 十进制数字、单下划线及浮点溢出也已按参考核对。

附加过滤使用 Python 标准库 re 的行为，和识别词/优先级规则使用的第三方 regex 模块分开处理。word 类排除组合附加符和其他连接标点，包含字母及各类数字；space 类补齐 Python 的 U+001C～U+001F。字符类内部、反向字符类及边界也在本批参考内。共用已有 Go 正则引擎和命名捕获转换，没有改变旧识别词及优先级规则的翻译行为。

新字段为 `policy.filter_params` 下的 `quality/resolution/effect/include/exclude/size`。字段缺席保留旧原生筛选含义；显式空字符串表示清除对应约束，不回退到旧值。旧 `source/resolution/hdr/include/exclude` 记录不被批量重新解释；独立编码、语言、字幕等约束仍保留。类型和资源边界在保存时校验，表达式和区间内容在原调用顺序实际访问时求值，保留原惰性错误语义。

搜索开始时冻结附加参数，每个站点的原始行在进入进度和最终列表前执行过滤；不匹配行不展示，出错清空结果并返回 `SUBSCRIPTION_FILTER_FAILED`。错误只包含失败字段，不记录正则或原始资源内容。预览和提交复核使用重新取得的原资源事实；识别词仅修改用于身份/季集识别的副本，不能让附加过滤错误地匹配修改后的标题。自动整季包判断也保持这一区别。

## 资源边界与未完成范围

单个原表达式/体积字符串限 64 KiB，转换后表达式限 256 KiB；缓存最多 512 项并限制转换权重预算 4 MiB，权重包含树节点估算，不是精确内存占用或 OS 沙箱。单次正则超时设置为 50 毫秒，每站附加过滤批次 context 5 秒；取消和超限明确失败。

313 组对照只证明这些输入。组合/作用域 ASCII 标志、ASCII 模式的更多大小写与反向引用边界、Unicode 数据版本和其他未覆盖正则构造仍须在正式规则迁移时逐条核验；不能据此宣布完整 Python 正则语言等价。后续不得默默改写原表达式来让迁移看似成功。

SubscribeGroup 的宿主事务、事件授权、真实订阅字段写入、热/冷缓存、下载历史及完整资源元数据、历史页读取分支、SDK 注册和原配置/KV/引用正式迁移仍在范围内。此依赖接线没有增加可执行插件或已迁移插件数量，正式服务没有切换。
