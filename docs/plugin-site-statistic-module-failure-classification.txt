来源边界
- 保持原三个返回值，新增只读 SourceUserModuleFailureKind。外部没有构造器，不能通过普通同文本或包装旧错误构造本次来源证明。
- 每次实际调用新建私有trace；只有最终错误是本调用登记的parser marker、无DTO，且ctx取消/请求guard检查通过后，才升为私有module failure。错误文本保持脱敏通用码，不带响应正文、站点凭据或Python repr。
- guard返回旧typed error仍保留errors.Is语义，但最外层分类器拒绝；冷快照UnmarshalJSON、DTO的err_msg、吞掉的seeding JSON错误均不提升。
- Go int64/指数范围、转换数字上限、JSON嵌套上限、HTTP体积限制及HH先前资源错误都不是已证实的原版模块异常。整数格式错误计数复用既有原十进制数字表，不以UTF-8字节数或空白长度推断限额。
- 同Client30个并发调用分别走parser、guard拒绝、取消路径；配置/guard固定，不用并发改配置伪造隔离测试。
