# v0.3.12 界面调整

按用户“优化页面 UI”的要求统一现有页面视觉，沿用已确认的 MoviePilot 操作流程。

- 深色侧栏与浅色内容区，青绿色主操作、统一文字和边框色；清理重复页脚。
- 用本地 SVG 组件替换字形图标，无新增包或字体网络请求。
- 统一站点卡片、状态与数据、编辑/导入弹窗；表单开关横向排列，底部按钮固定可见。
- 调整发现海报、影视详情、资源卡片、订阅和日历的排版；收紧资源页搜索及筛选区。
- 调整文件列表、整理历史、下载卡片、设置分区、任务列表和日志的间距与对比度。
- 修正手机文件菜单继承全局 details 的额外填充，行高恢复为 62px、菜单点击区 42px；文件列表根据顶栏与内容留白计算剩余高度。
