肉丝行为
https://rousi.pro 与 www 别名识别专用 rousi 适配，添加、编辑及更新凭据自动使用 API 页签。API Key 为原版 Passkey，通过 Bearer 请求头认证；普通配置、导入结果和资源 DTO 不返回密钥。
Go 实现 api/v1/profile（请求 include_fields[user]=seeding_leeching_data）、api/v1/torrents 搜索/分页/促销与详情中的 download_url 解析。签名种子材料仅允许同源 HTTPS，不向材料地址发送 API Key 或 Cookie；跨源及重定向明确失败。
旧版本已导入为 nexusphp 的肉丝记录在冷启动时选用专用适配，保留 ID、原网址及凭据，不在启动时重写加密配置。新增/保存/导入按网址规范化。API-only 导入不再误报缺 Cookie。
补齐 NexusPHP 与 MTeam 做种详情中已观测的 [做种者数量, 字节大小] 散点，只有完整列表且各项均可识别才发布分布；缺失或分页失败不冒充完整数据。
本修复不启用消息标记已读、签到或新的插件定时写入，不改变全局站点/下载器设置。
