原生插件长任务与工作器累计预算
日期：2026-10-18
状态：共享执行机制已完成合并、本机和隔离 NAS 验证，未部署。

问题与行为
原先 App 和 stdio Runner 各自给整次执行设置两分钟截止。原版插件按站点或下载器依次请求，虽然每个请求都在自己的超时内，整体仍可能超过两分钟。因此停止工作器并释放进程槽后，真实原生业务仍会被外层上下文提前取消。
现在先在两分钟内完成真实持久授权。只有安装版本与当前 Go 目录匹配、代际/配置/Run/Input 与 prepared 收据一致、原生方法和原始参数也精确匹配的 deferred 操作，才切换到应用生命周期上下文。名称、自报能力或动作字符串不能单独取得权限。普通调用仍保留两分钟整次截止；表单和只读查询仍为十秒。

Runner.ExcludeHostTime
默认 false，保持旧行为。仅由可信宿主在上述准入后启用。
启用后仍有累计两分钟工作器/握手/传输预算；进入可信 host 回调时暂停，返回后继续剩余时间，不按调用重置成新的两分钟。计时器带代次与互斥保护，避免 Stop/到期/恢复竞态。父取消始终有效，字节、帧、调用数、输出、进程及停止限制保留。
长原生任务继续使用自身网络请求超时、实例 owner、配置变更/停止排空与已确认/失败/未知收据。未知不自动重放，不增加任意无限期进程入口。

证据与范围
共享实现冻结来源中，协议30项普通与30项竞态通过，受影响 App45项普通、准入策略竞态以及实际源 AutoSignIn Engine/Visitor + Go SDK 长任务通过。源消费者真实耗时普通123.041秒、竞态124.088秒，并另测父取消。相同来源的三个 Linux 二进制在隔离 NAS 执行7项通过；其中包含测试工作器夹具，不能解释成7个不同插件已可用。
合并公共服务入口后的正式候选，再冻结2253个输入：App61项普通、策略/服务7项竞态、协议30项普通、预算5项竞态、vet、默认生产构建及 Linux CGO=0 构建均通过。合并候选 App 二进制在独占 NAS 容器执行61项全部通过，无跳过、失败或 OOM，独立确认资源已清理、三个已有服务未变化。实际源消费者目录89个文件与前述冻结证据逐项哈希一致。
