聚合站点开关：数字站点引用与保存恢复

更新日期：2026-10-18。适用于 MergeSiteSwitch 1.2 与 SiteStatistic 1.9.7 的
Go 实现；这是已验证的代码接线记录，不是原用户配置已经迁移的声明。

站点选择保留原版两种身份：系统站点为正整数，自定义站点为原字符串。
数字 1 和字符串 "1" 不相同；普通保存、表单、跟随和关联插件更新均不按
字符串拼写猜测身份。核心设置原有不透明站点 ID 只在受信映射边界转换。
SiteStatistic 原版未使用 statistic_sites 过滤采集，继续保留这一实际行为。

安装与重置在同一 SQL 事务记录引用协议。原 MoviePilot 导入先标记为未映射，
普通保存不能使其生效，即使原数字恰好与新站点编号相同。旧 Go 字符串格式
需要明确到字段、位置和目标的命名空间选择，并校验配置、站点映射、最后
初始化的跟随状态和待执行输入；转换、取消旧任务、新任务及收据原子提交。
当前只有宿主内部转换入口，还没有生产旧制品采集器，不能将夹具提供的
源码摘要当作实际用户来源核验，也不能声称旧用户配置已转换。

保存后规范化得到独立的配置修订，不改写已接纳任务的输入和原修订号。
持久收据绑定原执行身份、规范化结果与明确取消的冗余初始化任务。真正的
配置事务提交后，即使 SDK 工作器丢失回复，也由实际提交收据恢复结果；
没有收据的失败保持失败，损坏收据不作为成功。未映射任务在启动时保留，
不覆盖最后初始化的跟随状态，也不阻塞其他已具备合法协议的插件。

验证范围

- 原版安装源码的 64 条数字引用执行参考；原字符串样本不充当数字身份依据。
- 协议主轮冻结 1961 份输入：130 项实际 App 普通、竞态及 NAS 测试通过；
  15 项内置插件测试、vet、生产构建及 Linux CGO=0 构建通过。
- 丢失回复修复轮冻结 1962 份输入：27 项相关 App 普通、竞态及 NAS 测试
  通过，另有 15 项内置插件测试及上述构建检查。27 项不冒称重跑了 130 项。
- 合并后的实际程序已在独占浏览器实例选中两个站点、保存并重开表单；
  实际配置保留整数 [1,2]，两个核心站点启用状态同步更新。截图和摘要见
  plugin-site-reference-verification.json。
- NAS 使用独占目录、无外网隔离容器与合成数据；测试资源已移除，原服务
  身份、启动时间和重启次数保持不变。没有访问真实站点或修改用户配置。

边界：非保存引起的启动跟随注册仍是幂等操作，没有逐任务操作收据；不能
扩大为全部启动丢失回复场景已闭合。AutoSignIn、IYUU 等关联业务的完成度
单独计证。原配置/KV/文件正式迁移仍为 0，新增插件部署和启用尚未执行。
