# v0.3.2：任务队列说明

任务队列之前主要显示任务类型和内部 ID，不能看出正在处理哪部影视或哪个文件。本次给列表和详情增加由本地记录生成的任务摘要，不改变任务的调度、执行、重试或取消逻辑。

- 列表直接显示动作、影视名、年份和季集；没有影视身份的资源任务显示原始资源标题。
- 文件任务展示源/目标路径和本次文件数；下载提交展示下载器与保存目录。批量任务只统计实际选中的文件。
- 状态旁显示当前动作、等待/重试/完成等阶段，以及当前任务最近一条实际记录。没有百分比的任务不伪造进度。
- 下载提交成功明确写“已提交下载器”，不表示视频已下载完成。
- 详情先展示任务对象和路径；ID、工作流和参数放在折叠的技术信息中。详情执行记录只查询当前 job，不混入同 workflow 的其他任务。
- 已移除关联记录的旧任务显示“关联资料不可用”；仍可查看其真实状态和历史事件。

覆盖资源下载、影视下载、文件整理、重整旧文件清理、元数据刮削、飞牛入库核对、订阅检查、媒体目录核对和媒体文件检查九类任务。摘要只读取本地数据库和配置中的名称，不读取外部站点，也不回传关联记录中的加密下载器快照、种子材料引用或带认证的 URL。
