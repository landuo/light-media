插件界面还原 — v0.4.11（2026-10-23）

依据
原版 MoviePilot 实际运行页面 http://192.168.8.129:3000/#/plugins，以及本机 MoviePilot-Frontend 的 PluginCard、PluginConfigDialog、PluginDataDialog、PluginLogDialog、Vuetify 主题样式。原项目只读。

修改
- 卡片显示原版插件图标及图像主色，统一 108px 封面、40px 作者栏、三行简介、内联版本、状态点和操作菜单。图标本地打包，缺失图标使用原版通用图标；不展示不存在的评分或下载量。
- 页签图标、40px 页签高度、筛选与排序按钮、卡片网格和文件夹外观选择按原版恢复。
- 配置和数据弹窗恢复原版标题、独立关闭按钮、正文间距，以及左侧查看数据、右侧保存的操作布局。
- 修正主题差异：弹窗 12px 圆角，正文 20px 内边距、40px 开关、可见的关闭态轨道、全宽分隔线和 12px 代码编辑器。隔离宿主页面对插件表格、按钮的样式影响。
- 日志弹窗恢复原版标题与关闭按钮排版、级别颜色。配置保存、执行与日志接口保持原有行为。

验证
开发目录：178 项前端测试通过；生产发布目录：174 项前端测试通过。两份 TypeScript/Vite 构建通过，Go web 嵌入资源验证通过，Linux amd64 无 CGO 构建通过。
合成页面验证开关、筛选、菜单、配置与详情切换、日志窗口；正式发布静态资源再次独立验证开关颜色，避免 CSS 加载顺序差异。
NAS 隔离容器启动与认证初始化验证通过，随后发布到 3120。生产浏览器核对 7 个真实插件图标、分类策略配置和系统进程数据，最终浏览器无错误或警告。未在生产保存配置或执行插件写任务。
