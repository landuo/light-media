本次候选按 NAS 实装的 CustomHosts 源码和 python_hosts 行为校正，尚未作为第六个完成项计数。当前生产仍为 v0.4.5，实际完成 5/23；部署和正式配置迁移另计。

已实现原版表单、启用/停用、无效行通知、错误 Hosts 回填、整体配置替换、PluginReload 和启动时重载。停用清理自身标记之后的内容；停止插件或卸载不额外清理，沿用原版 stop_service 的行为。空配置不读写文件。所有输入无效时不写文件，但更新错误记录。写入失败保留原版通知和配置状态，同时在本程序执行历史中明确记录失败。

现有系统 Hosts 按原版 python_hosts 解析并规范输出，保持原地址与域名语义。插件只能修改新程序容器内的 /etc/hosts，以及按原版规则规范该文件原有前缀；它不能访问 NAS 或旧 MoviePilot 的 Hosts。128 KiB 上限、无符号链接、锁、快照和失败恢复继续由宿主检查。超过本程序边界时明确拒绝。

国际化域名使用纯 Go 的 IDNA2003/原 Python stringprep 与规范化数据。5674 个原版实际 IDNA 输出、12892 个实际规范化输出，以及 49 个原插件合成场景均对照通过。参考脚本只用于开发时只读提取和内存模拟，不是产品运行依赖。

验证：核心普通/竞态各 6 项、55 个含子项结果通过；应用普通/竞态各 24 项、68 个含子项结果通过。默认跳过的实际私有配置 stdin 测试已分别独立执行普通和竞态，核对加密、冷重启、收据重放、保留用户修改和失败整体回滚。真实 Go 产品进程启动/退出及迁移 CLI 的锁、预检、导入、重放通过。前端 163 项及构建、静态检查、原生与 Linux CGO=0 构建通过。

NAS 独占、断外网、非 root、只读根文件系统的容器已验证真实 Go SDK 写入、域名解析、HTTP 连接和停用恢复。测试容器及独占目录已清除，旧 MoviePilot、qBittorrent 和生产容器身份未变。此证据还不是正式用户配置已迁移的证明。

使用 Docker 时，应用账号必须能写入专属 container-hosts 普通文件，并仅将该文件挂到本程序容器的 /etc/hosts。compose.custom-hosts.yaml 是可选覆盖文件，明确禁止自动创建缺失路径。可先从本程序原容器读取初始 /etc/hosts，保存为该独占文件，设为 0600、属主 1000:1001，再使用该覆盖文件重建新程序容器。不要直接绑定 NAS /etc/hosts。

原用户配置已只读核对：启用、1 行 Hosts、0 个错误项、0 KV、0 独立插件文件。配置正文只经 RAM/stdin 和目标 AEAD 存储，不写入报告或普通文件。正式迁移仅允许已审阅的来源、版本、源文件摘要、配置摘要及空数据范围；普通迁移不因此获得启用权限。迁移 CLI 不运行插件；首次新容器启动才应用到它自己的 Hosts。
