日期解析器初始化内存修正（2026-10-21）

范围与状态
全 Go 运行时；不引入 Python 服务。此修正针对站点统计原版日期解析所需的 Go 依赖，并非一个插件迁移完成项。生产仍为 v0.4.8、正式迁移 7/23，未部署本修正，旧 MoviePilot、qBittorrent 和媒体文件均未改动。

实现
将 github.com/markusmobius/go-dateparser v1.4.7 保留为 third_party/go-dateparser 本地分支。205 个生成的语言初始化函数仅重命名，由 sync.Once 在第一次 GetLocaleData 时按原文件词法顺序调用；语言表和函数主体未删改。206 份还原格式化比较覆盖 205 个构造函数与查找入口，均与上游相同。保留 BSD-3-Clause 许可证及上游生成器。移除可选 go1.27.1 toolchain 偏好，保留 Go 1.26 要求，避免构建自动下载其他编译器。

主模块 replace 指向本地分支。Dockerfile 在 go mod download 前复制该分支，并将许可证带入运行镜像；Makefile 的 dateparser-check 执行实际依赖测试和冷启动并发 race 测试，check 包含此目标。生成语言表时必须重新应用此补丁并验证，构造函数丢失将直接编译失败。

内存与限制
三个仅执行 Go 测试二进制初始化、不运行测试/应用/工作任务的本机样本：原实现最大 RSS 为 87,834,624 / 87,867,392 / 89,767,936 字节；修正后为 41,582,592 / 41,304,064 / 41,582,592 字节。此数据仅说明初始化成本，采样期间另有回归运行，不据此声称隔离延迟指标或生产服务器峰值。第一次真正解析日期仍加载全部语言表，没有承诺解析后的长期内存降低。

验证
冻结物理副本后执行依赖本身 16 个包的正常测试、256 个调用者跨 8 个语言的冷启动 race；站点协议 44 个顶层/246 个含子项测试正常和 race；相关应用 48 个顶层/167 个含子项正常和 race；原版 2,133 条账户历史的正常和 race，以及原版 MTeam/Nexus/HHan SDK、加密冷恢复和撤销边界。均以终态日志计证。
原生/Linux/modernconly 编译、vet、模块校验及 Docker 依赖复制阶段均通过；没有构建实际 Docker 镜像。NAS 使用独占无网络、只读根文件系统、1 CPU/512 MiB 测试容器；具体结果、清理、生产身份与哈希核对见对应 verification.json。页面没有改动，未重做页面验收。

保留失败
原型首次复制因上游只读目录失败，随后使用新物理目录；原型首次测试触发上游可选 toolchain 下载并因 EOF 失败，未安装该编译器。改用本机 Go 后测试通过。失败未作为通过计数，不覆盖此前 Nexus 组合 race 超时证据。

边界
原版 Python dateparser 与 Go 移植版本不同；本次证明已列原版样本与依赖自身测试，不能据此宣称所有罕见日期字符串都已等价。站点模板、肉丝专用采集、完整通知链与执行交接仍需独立完成，不以本修正增加已迁移插件数量。
