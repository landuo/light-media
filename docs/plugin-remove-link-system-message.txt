Publication rule:
Only this invocation's newly inserted diagnostic may enter the existing FIFO
once its transaction is known committed, either by success or exact sealed
receipt + state + notification read-back following a lost ACK. The old-fact
branch and cold recovery never publish. Rollback, unverifiable ACK, a corrupt
receipt, an ordinary untyped factory error or missing blocked checkpoint
publish nothing. The existing configure Guard and effect lease remain held;
no watch restart or lifecycle success is inferred from notification delivery.

The queue is intentionally ephemeral. A crash after SQL commit and before
queue publication may lose the popup but retains diagnostic history. It is
not a durable exactly-once outbox. Cancellation observed at queue entry and
a closed queue suppress live delivery; no external notification is sent.
Shared dedup semantics remain unchanged, including dedup across instances.
