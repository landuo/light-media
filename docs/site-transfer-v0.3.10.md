## 站点导入与导出

「站点管理」提供导入和导出。兼容 MoviePilot 前端 `SiteCardListView.vue` 导出的顶层 JSON 数组，以及本应用的 `{format:"light-media-sites",version:1,sites:[...]}` 格式。导入文件上限 2 MiB、128 条，保存后的站点上限沿用 32 个。

MoviePilot 字段映射：`name`、`url`、`cookie`、`apikey`、`is_active`；馒头主页规范为 API 地址，`domain` 如存在必须与地址一致。仅支持馒头、憨憨、UBits、家园、1PTBA 已适配的 HTTPS 域名。未知站点明确跳过，非法条目逐项失败，不输出原始凭据或错误 JSON 片段。

同地址更新保留站点 ID 和订阅引用，不替换无关配置。本应用不同 origin 保留各自条目；MoviePilot 的单站换域名兼容仅作用于导入前唯一的同类型站点，且新地址必须提供新凭据。同地址未提供凭据时保留已保存凭据。重复导入更新原记录，文件内重复项不覆盖先前条目。

MoviePilot 的 User-Agent、代理、渲染、超时、RSS、下载器绑定、过滤、Token、优先级和流控等选项未等价迁移，有实际设置时显示提示。原版每日流控不直接换算成本应用预算：新站默认每日 600 次，更新已有站保留预算。导入成功仅表示配置保存，明确显示尚未测试连接，不把配置导入当成站点连通成功。

导出文件包含迁移所需的 Cookie/API Key，通过经认证的附件响应提供，禁止缓存；普通 settings/manage 响应继续脱敏。导入和站点编辑、刷新、启停、删除之间互斥，防止在途旧配置覆盖新结果。
