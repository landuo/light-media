# v0.3.17 飞牛影视内网连接

历史记录：5666/5667 的原版入口兼容在 [v0.3.20](fnos-root-entry-v0.3.20.md) 完成，本页保留当时的实现与实测状态。

实机故障：用户保存的地址为 `https://192.168.8.129:5667/v`，启用状态和账号密码均已配置；连接测试在首次版本请求时返回 `TRANSPORT_FAILED`，尚未认证。NAS 本机正常校验证书的请求报 `self-signed certificate`。没有关闭 TLS 校验。

Memos《NAS 宿主机与应用中心服务入口》提供内网影视端口背景。本次在 NAS 上重新核验 `http://192.168.8.129:8005/v/api/v1/sys/version`，业务 code 为 0，影视前端 0.9.8、后端 0.8.43；这一步只证明版本接口正常。

修复内容：

- 测试与实际影视服务共用地址规范化。支持根入口和 `/v`、`/v/`；HTTP 支持私网、回环 IP 和 localhost，HTTPS 继续正常验证证书；不允许凭据 URL、查询串、片段或其他路径，不跟随重定向发送凭据。
- 证书、超时、端口拒绝连接和一般网络错误分别显示固定中文原因，不返回底层错误中的地址或凭据。页面直接提示业务成功或失败，诊断数据可展开；不会把 HTTP 200 当作连接成功。
- 更换真实地址或账号且密码留空时，拒绝保存并保留原配置，明确要求重新输入密码；同一地址的等价 `/v` 形式仍保留已存密码。防止静默清空密码，也不自动向新地址复用旧密码。

合成验证：真实 httptest HTTP 服务核对请求签名、登录、鉴权和媒体库读取；自签名 TLS 仍被拒绝。浏览器仅使用本地内存合成配置，检查证书失败原因及内网连接成功提示，没有连接真实站点或媒体服务器。
