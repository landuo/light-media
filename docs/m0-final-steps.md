## 已完成的来源到 NFO 工具

`cmd/metadatacheck` 固定核对夜王电影、生活大爆炸父剧及 S07E17、诛仙父剧及 S04E05。它只从 stdin 获取用户已授权的任务相关凭据，未配置时零请求并返回未验证。主任务已按最新授权从原 MoviePilot 项目只读取用本次所需 TMDB 凭据并完成五次官方查询；没有修改旧项目或保存凭据。具体 API、身份、实测结果与错误契约见 [metadata-contract.md](metadata-contract.md)。

`experiments/metadata-nfo` 不请求网络，只核对该五条报告并生成对应五份 XML 的计划。要求全部记录通过、来源为 TMDB、每个 sample 唯一、类型/固定 ID/父剧上下文/季集/日期一致。单集 uniqueid 使用单集自己返回的 ID，父剧 ID 只用于父关系。当前兼容输出同步增加同值 `<tmdbid>`，不增加第二份身份输入；历史 v1 `uniqueid` 单字段精确 profile 仍可重放，custom-only 合成 XML/JPEG 不被改写。相同数值在不同类型命名空间中不被合并。该工具保留输入和五份 NFO 的 SHA-256；报告声明、哈希和 run ID 均不能独立证明远程来源真实性。

工具默认不写文件，只有明确的新 work 直属目录和 apply 才创建五份 NFO。验证与全部 XML 编码在创建目录前完成，失败输入不落盘；不覆盖既有根目录或文件。根电影/父剧只写所确认的标题、年份和 ID，完整来源日期保留在清单；单集额外写 showtitle、season、episode 和 aired。它不生成图片、视频或演员，不创建飞牛媒体库，也不改既有合成实验工具。
