# P0 应用验收记录

> 本文保留 v0.1 的阶段性测试事实。用户实用后指出站点管理、下载器配置、文件管理、整理历史、搜索与订阅等操作存在明显缺口，因此不能据本文将 v0.1 认定为用户需求已完成。v0.2 已按原版 v2 重新实现主要操作，当前验收以 [v0.2 操作对照](operation-parity-v0.2.md) 为准；下文的“最终包”和测试数量仅指当时 v0.1。

核对日期：2026-10-15。需求基线为 [design-v1.4.txt](design-v1.4.txt) 的 FR-01–FR-21；本记录描述独立新项目的应用功能与实测证据，不沿用 M0“技术路线通过”作为应用完成结论。

当前已具备可操作的 Go + Vue + SQLite 应用，NAS 应用端口为 **3120**。最终新包、全量回归、五站真实种子预览、材料归档、下载后纠错和恢复已核对。**72 小时整应用混合负载稳定性尚未完成**，因此本文件不作“全部生产指标已验收”的结论。

运行时不依赖 Python、Node、Redis 或独立数据库服务；构建前端需要 Node。旧 MoviePilot 和旧 Go 项目未被修改，旧业务数据没有被迁移或改写。经授权取用的已有连接配置属于只读参考，不把读取权限扩展为修改旧服务的权限。

## 验证口径

- **真实浏览器**：浏览器使用真实新应用 API；文件操作仅涉及新建的小视频和独占测试目录。
- **真实服务 / 实际传输**：明确指出调用哪个实际服务、执行哪些操作，以及是否真的传输了文件字节。
- **localhost HTTP / 协议 fixture / 自动回归**：使用真实应用代码及持久数据库，但部分外部接口或元数据可能由受控样本提供。它们不等于实站或实际下载。
- **待最终验收**：功能或测试已经存在，但最终运行结果、最终部署包或指定实机演练尚未在本文件确认。

各证据的版本、时间、实例和范围独立。不能把“五站搜索 + 隔离合成种子下载 + 真实 TMDB 整理 + 飞牛临时库核对”写成同一次“从五站真实影片下载直至正式库可见”的运行。

页面入口使用当前应用地址后的 hash，例如 `#discover`；无需另起前端服务。API 均以 `/api` 开头并要求管理员会话，登录与初始化接口除外。

## 资源、稳定性与兼容边界

最新短时观察的主进程 **VmRSS 28,608kB** 和容器 **18.97MiB** 为五站查询/预览后的一个样本（原始快照见E15）；两者的采样时间、记账口径可能不同，不能相减或当成同一时刻总成本。这些快照不代表30分钟预热后的空闲上限、五站搜索/订阅检查/整理并发峰值，也不包含外部qBittorrent、Transmission、飞牛影视的全部成本。

**72小时整应用混合负载尚未执行完。** 仍需记录RSS、容器内存、Go堆/goroutine、队列堆积、WAL、图片/日志增长及OOM情况。M0的SQLite合成数据库、一次文件探针或空闲截图都不能替代该项，不据语言选择宣称已比Python方案节省某个比例。

当前目录存储只包含本地/NAS挂载。硬链接以实际设备/文件系统边界为准；挂载不可达不是空库。TLS不因联调失败关闭校验。远端API/站点模板按已测版本和样本维护，连接成功不保证全部字段或未来版本兼容。

受保护材料的P0目标：随机/不可推断的opaque引用，AES-GCM加密；按原始材料SHA256去重，不能仅按infohash混用；已关联Intent的材料归档不自动过期，未确认预览孤儿24小时清理；默认总额256MiB，可设32–2048MiB。预算满时明确拒绝新预览，不能静默删在用材料。内部解析只供core使用，没有新增HTTP下载私有种子接口。**重启精确还原、密文无passkey、不同tracker原始字节不混用、损坏拒绝、总额保护、确认事务pin及定时清理回归均已通过（E17）。**

P0事件只在事实状态事务成功提交后可读。内部消费者未来按持久序号读取，可能重放，必须按event_id去重；事件引用与因果字段不是调用下载器/修改文件的授权。此轮没有插件消费者、交付ACK、运行器、安装管理或安全沙箱验收。
