## 找到主要分配路径

启动后首个二进制快照 106,207 字节，`go tool pprof -top -cum -sample_index=alloc_space`，符号文件与 profile 的 ELF Build ID 一致。该快照是**进程启动以来**的采样估计，并非五分钟计数的精确分解。`brushflowlanduo.(*Core).CheckPromotion` 累计约 84.22%，其中 `promotionExpiry` 路径约 66.61%；插件 `compat/pythonre.(*vmState).push` 单函数直接分配约 58.03%。嵌套比例不可相加。这是临时对象分配的实机证据，不是活堆占比或泄漏证明。
