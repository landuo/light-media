# 系统进程 1.1

2026-10-21：已随 v0.4.3 上线并正式迁移。当前实际完成 **4/23**，剩余 19 项仍在开发；这不是全部插件可用的声明。生产收据见 [迁移记录](plugin-system-process-deployment.json)，验证范围见 [验证报告](plugin-system-process-verification.json)。

依据原安装的 SystemProcess 1.1、psutil 7.2.2 和实际安装的前端实现，提供原三字段配置、详情表格及仪表板。进程按 PID 降序，显示名称、CPU、内存和运行时长；只读取当前光影容器的进程。CPU 按原版每次构造行时的两次读取计算，保留原一位小数和运行时长的日期取余行为，不自行平滑或限制百分比。预期的进程退出、无权限和僵尸进程按来源处理，其他读取错误明确失败，不返回空表假报成功。

仪表板支持原版编辑、拖动、调整尺寸、重置、排序、显示开关和桌面／平板／手机布局。刷新间隔与配置值保留来源语义，隐藏组件不轮询；设置保存后重新读取数据。原表单的缺省值不覆盖实际用户配置。

迁移读取原配置与同一来源用户的五个 Dashboard 记录，完整保留未知组件标识及布局内容，以目标应用密文存储。配置、五份偏好和迁移收据在一个事务内提交，注入中途失败可全部回滚。来源 KV 为 0、数据目录缺失，不虚构空历史或文件。重复来源返回原收据，不覆盖后续用户修改。

该已核对的编译内置插件仅有只读进程能力，因此按原持久配置启用其页面和仪表板；导入时不创建工作器运行、计划或事件。冷启动产生一次成功的初始化，没有业务执行或媒体任务。其他插件的普通迁移继续保持平台禁用状态，不借此启用下载、签到或清理。

验证分开计证：第一份冻结组合的全量普通回归 1,796 项通过（含子测试 43,130），6 个显式外部／专用环境检查跳过；最终修正只改变迁移工具、存储中的专用只读激活分支和对应测试三个文件，普通与竞态各 16 项通过（含子测试 32）。最终服务的实际 macOS 进程读取单独按原 8 秒预算通过。前端 163 项通过，构建、vet、macOS/Linux 服务及专用 Go 工具构建通过；3,399 个源码文件和 5,326 个编译输入未漂移。以上有重复覆盖，不相加作为不同测试数量。

原版进程采集的首次并发 macOS 检查曾达到 8 秒预算而失败，原记录保留；相同冻结输入在相同预算下串行通过。临时迁移还实际发现并修正了只读插件被通用迁移禁用状态隐藏的问题。最终二进制已走通实际来源选取、只读预检、加密导入、重复收据、冷启动、登录后的真实进程仪表板及五份偏好查询；临时实例已清理，没有操作原版站点、下载或通知。

生产页面已核对详情与实际刷新；页面读取之后再次确认配置和五份偏好密文未变。原有目录监听正常更新自己的文件观测记录，未新增媒体任务。原有三个插件的配置及启用状态、分类文件和加密密钥保留；原 MoviePilot 与 qBittorrent 的容器 ID、主进程、启动时间和重启计数未变。这些容器元数据不代表读取了原应用进程的内存状态。

原安装顺序、文件夹及其他插件自身的全部平台行为仍属于后续迁移范围；本次五份仪表板偏好迁移不表示其他尚未迁移插件已可用。
