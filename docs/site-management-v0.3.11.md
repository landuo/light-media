# v0.3.11 站点管理与 NexusPHP

本次修复用户实际遇到的 `SITE_NOT_ADAPTED` 导入提示。v0.3.10 将五个首发站点写成了导入白名单，导致其他站点直接被跳过；该限制已取消。原五站专用适配保留，其余合理公网 HTTPS 域名可按通用 NexusPHP 保存、导入并执行协议请求。

## 可用流程

站点管理按 MoviePilot 本地源码 `SiteCardListView.vue`、`SiteCard.vue`、`SiteAddEditDialog.vue`、`SiteImportDialog.vue` 对齐：网址新增、编辑字段顺序、Cookie/UA 和 API 页签、状态和优先级、卡片测试/账户数据/编辑/删除、排序、浮动添加和导入导出入口。导入采用选文件或拖入、前五条预览、明确开始、逐站进度和结果；不额外要求逐项勾选。点击站点卡片在当前页浏览该站最近资源，支持关键词、分页和既有下载器/下载目录确认。

导入支持原版 JSON 顶层数组及 v0.3.10 的旧封装。忽略原版数字或 null 数据库 ID，以规范网址匹配本地记录；原版开关的 bool/0/1、数字的整数/字符串、可选 null 兼容处理；迁移 Cookie、API Key、UA、超时、状态、优先级、限流字段。导出改为 MoviePilot 顶层数组，保留 `_light_media` 扩展用于本应用每日预算往返；原版可忽略此字段。

所有导入都按规范地址更新，不能按同为 NexusPHP 或同类适配而合并不同站点。主页/API 已知别名先规范化。同地址重导入保留 ID 与引用；不同地址不会复用已保存凭据。配置和一次导入上限均为 128 站，文件 2 MiB；搜索和订阅站点范围同步扩展。

站点配置可先保存再补凭据、测试连接。停用站点允许用户手动测试、浏览资源；不会因此开启后台搜索和订阅。缺失凭据、登录页、验证挑战、结构不符或网络失败明确反馈，不能把 HTTP 200 或保存成功当成可用证明。

## 协议与执行

通用 NexusPHP 复用 `torrents.php` 查询、标准 `download.php` 种子材料和账户/做种页解析，新增表头识别以适应可选列、列顺序等变化；材料仍验证为有效种子。UA 和请求超时参与实际连接，修改 UA 后清除旧认证冷却。最小访问间隔、单位周期请求次数与已有每日额度共同作用于搜索、账户数据和下载材料请求，使用持久请求账本。间隔在 5 秒内的等待可取消，更长的限流直接显示建议重试时间，避免长时间占用站点锁或让界面持续等待。现有账本的秒级精度采用向上取整，保证最小间隔不被缩短。

通用请求限定配置的地址和同源材料，不转发凭据到重定向目标。公网域名在连接时解析并核对地址后拨号，保留 TLS 主机校验；连接池复用。普通配置接口隐藏 Cookie、API Key、Token、RSS、备注中的私有内容，只有用户明确导出时生成含凭据文件；日志继续脱敏。

## 明确边界

通用 NexusPHP 不等于支持所有 PT 程序或任意定制页面。定制 API、非 NexusPHP 模板、强制浏览器验证等仍需单独适配；现有馒头、憨憨等专用处理继续优先使用。RSS 调度、站点绑定下载器、Token 认证、独立代理、浏览器仿真、账号密码自动获取 Cookie 尚未接入；导入保留兼容字段、显示提示，界面不把这些字段伪装成已生效的开关。没有运行这些能力的后台任务。
