# 订阅识别词与下载上下文

本切片是订阅规则自动填充及资源筛选的核心依赖，不增加已迁移插件数量。以实际安装版 MoviePilot 的订阅 `custom_words` 和搜索 `Context` 传递为参照；新项目仍全部使用 Go。

## 编辑与存储

订阅编辑进阶页沿用原版“自定义识别词”多行控件。非空原始字符串按 `split("\n")` 替换全局词表，保留空行、空白和顺序；空字符串或 null 清除局部覆盖，恢复全局规则。旧客户端编辑时省略字段则保持原值。这里不合并两份词表，也不自动 trim。

局部值保存在独立加密表 `subscription_words`，密文绑定实际订阅 ID。保存与订阅修订、旧任务取消及创建事件在同一事务内提交；解码或后续 SQL 失败不能消耗修订或覆盖原词表。只有鉴权后的订阅编辑响应返回原始文本，普通 Subscription、Intent、搜索请求、预览和公开事件均不序列化词表。现有删除入口将订阅标记为 cancelled，保留其历史和密文；显式清空识别词才删除局部覆盖行。

原始 JSON 字符串先验证 UTF-8，再解码，避免标准 JSON 库将无效字节替换成其他文字。词条数、单行、总字节和加密值大小均受既有识别词与插件数据边界约束。订阅编辑请求需容纳合法的大词表，不能受其他普通接口的 2 MiB 请求上限截断。

## 执行范围

自动检查先确认实际订阅 ID 和修订，再选择局部或全局识别词，同时冻结 source mode、制作组、占位符及后缀选项。该私有上下文贯穿搜索识别、排序、合集资格及材料核验。Include/Exclude 等原始资源筛选继续读取未被识别词改写的标题和副标题。原版优先级 `size_range` 的集均体积另行用全局识别配置计算分母，不继承候选的局部词表；排序则使用该候选 Context 的局部解析，两者不能混为一条规则。

确认下载时将完整配置写入加密下载源快照；普通 Intent 不含这份配置。进程重启和下载前重查继续使用所选配置：新 Add 可以按重新核对的资源标题解析，但不能改用后来保存的全局或订阅词表；下载器已有相同 hash 时保留此前选择快照。下载接受事实、快照和 outbox 同事务提交，随后 SubscribeGroup 读取实际接受的资源属性。

已认领下载的文件检查、纠错预览和完成整理继承对应 Intent 的冻结配置。没有选择快照的旧 Intent 保持原先全局处理行为；不按相同 TMDB 编号借用其他订阅。普通文件管理的手动整理和原生资源下载各自选择当前全局规则，不能继承另一条下载的局部规则。

## 页面图标

原版表单传入 `mdi-*` 图标名，旧 SVG path 渲染器会将这些名称误当路径。现在沿用原项目的 Iconify 与 MDI 形状，固定 `@iconify/vue` 4.3.0、`@iconify-json/mdi` 1.2.3；构建时只收录源码声明和 Vuetify 默认别名依赖的图标，使用离线组件。当前集合为 42 个名称、8,209 字节，无运行时图标网络请求。许可证随构建放在 `licenses/`。

## 验证口径与剩余工作

回归覆盖真实 HTTP 的原文往返、省略/null/空串、鉴权和非法 UTF-8，密文绑定、SQL 失败回滚及实际关闭重开；合法 2.52 MiB 词表经 POST、GET、PUT、关闭重开及再次编辑完整保留，字段及 18 MiB 请求超限不会改变修订或密文。流程测试覆盖两个订阅的并发隔离、真实订阅选择两个 Intent、全局配置更改、重启后的新 Add/已有 hash、Go 插件工作器及下载完成后的文件处理。

本切片已通过全仓普通与 modernconly 检查、App 指定范围 race 91.129 秒、插件及元数据包 race、vet 和模块校验。之后按原源码纠正 size_range 的全局分母，最终 App 目标普通 8.361 秒及相关范围 race 16.780 秒均通过；没有将先前全仓结果冒充为这次修正后的全仓重跑。前端 122 项测试、构建及格式检查通过，最终样式修改另有真实浏览器验证。

独立浏览器测试实例实际登录、保存原始文本、重新打开、服务重启后重开、清空并刷新均通过；桌面 720px 弹窗与 390px 手机宽度无横向溢出，字段图标实际生成 SVG path。修正了沿用普通 textarea 的零内边距造成 Vuetify 顶部文字被遮罩的问题；全局制作组和占位符表单同步恢复原控件内边距。使用的是一次性合成管理员与剧集，没有调用用户真实 TMDB、站点或下载器。

最终 App 测试程序在 NAS Alpine 3.22 的 UID 1000/GID 1001、无外网、只读挂载、256 MiB 内存、128 MiB tmpfs 和 GOMEMLIMIT=64MiB 环境终态 PASS，包含大 HTTP 词表、重启、实际两 Intent 下载、插件工作器及优先级配置来源回归。程序 SHA-256 `2dd8fb566c084054211ca96e5ba64489482dcf99be6cea2ba233f8ca023848c5` 已在本机和 NAS 核对一致。测试容器、本机临时服务和两端独占数据目录均已清理。

这不是完整 MetaInfo 等价声明：核心身份识别仍使用本项目已有解析器；Rust/legacy 资源属性解析与核心身份解析的边界见 [release-resource-metadata-go-port.md](release-resource-metadata-go-port.md)。原生下载虽冻结 DownloadAdded 配置，但其目录监听整理仍使用监听时的全局规则，不能扩大上述 Intent 验证结论。原版 RSS 路径的特殊已有 Context 行为、原版全部识别指令和独立规则测试工具仍需逐项实现与验证。正式用户词表、订阅及插件 KV 尚未迁移到生产服务。
