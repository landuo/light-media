站点管理修复 v0.4.17（2026-10-24）

发布分支从已验证生产提交 cb9551b 建立，不包含 main 中尚未验收的插件实现。

修复
- 移除站点名称搜索与状态筛选，工具栏仅保留“全部测试”。对所有站点的固定快照执行，最多 3 站并发；排序保留在站点更多操作菜单内。
- “站点统计”空白是没有 Vue 指令的原生 template 元素导致其子元素不可见。移除此包装，四项原有汇总正常渲染，并保留已获取站点数；未知数据不当成零。
- 卡片使用原版运行页面实际缓存的 17 个站点图标；域名别名映射到本地资产。其他 HTTPS 站点尝试根目录 favicon.ico，丢弃路径、查询及用户信息，失败回退原版默认图标。
- 萝莉首页已采用 userdetails.php?uuid=...，做种接口使用 useruuid。补齐经过格式验证的 UUID 账户标识及对应请求参数；保持原有数字 ID、同源、凭据与登录检查。

验证边界
- 前端 202 项测试、构建；站点包全部 Go 测试和 race；应用站点导入、管理、身份、统计及肉丝相关测试；相关 race、vet 与 Linux 构建通过。
- 浏览器独占合成数据：17 图标可见，统计四项及来源计数正常；全部测试 17 项各一次、并发峰值 3；390px 手机宽度无横向溢出。
- NAS 实机只读使用既有萝莉凭据，验证账户身份、上传下载、做种数量与体积，解析警告为空；HTTP 200 之外核对了业务字段。没有下载真实种子。
- 原 MoviePilot 仅作只读参照，没有修改旧项目、配置或站点。凭据与账户 UUID 未进入提交材料。
- 生产发布和发布后浏览器结果见同名 deployment/verification JSON。原有其他站点本次未逐站重新认证，批量测试证据为合成样本。

发布后实际浏览器：17 图标全部加载、工具栏仅全部测试、统计汇总可见。单独刷新萝莉业务成功，账户弹框有上传下载、做种数和体积及图表；因请求耗时卡片标记“连接较慢”，不再为“连接失败”。
