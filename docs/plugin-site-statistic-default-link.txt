站点数据统计：默认插件链接与接受时冻结（开发阶段，未部署）

2026-10-21。在 bb2834c7c1f58ed284521ac4cb59295dbe13664d 后独立修复 SiteStatistic 通知缺少插件基类默认链接的问题。本轮只接 SiteStatistic；新的内部 helper 可供后续插件复用，不代表 RemoveLink 或其他插件已接通。正式迁移仍7/23。

配置与冻结
- 复用现有 Settings.AppDomain / app_domain，不新增插件专属域名、不从请求Host猜部署地址、不读取或修改真实生产配置。AppDomain可通过现有设置API配置；本轮未新增前端编辑入口。
- 显式非空链接保留；默认域名为空得到nil，否则按插件类名SiteStatistic构造 #/plugins?tab=installed&id=SiteStatistic。分身不把instance ID当插件类名。
- 新接受事实采用私有box Version2，AppDomain使用非nil指针表达已冻结（可指向空串）。接受时的域名、完整信封、历史链接与摘要在同一事务固定，之后编辑AppDomain、新请求、冷启动或重放都不能改变原事实。新事件才读取新配置。
- 原Version1消息省略该新字段，继续按原无链接信封验证；不补发、不把旧记录改写成v2。版本/冻结字段组合无效、信封或历史链接被篡改均拒绝。
- 无法构造的地址返回固定脱敏错误并回滚接受事务，不把失败伪装为空链接成功，不写新的通知去重成功状态。
