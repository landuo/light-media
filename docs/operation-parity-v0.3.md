# v0.3.0：按原版操作校正 P0

本文保留 v0.3.0 当时的状态；下载管理、文件管理和整理历史的当前行为以 [v0.3.1 校正记录](operation-parity-v0.3.1.md) 为准。

本轮依据用户 2026-10-15 的明确要求，对照本机 MoviePilot v2 前后端源码，校正 P0 的页面入口、字段与执行流程。下载器应用内路径映射按用户要求取消；Docker 挂载提供文件可见性。本记录描述本轮变更与验证，不代表 MoviePilot 全部高级功能已经复制。

## 操作约定

| 操作 | 当前入口与行为 |
| --- | --- |
| 站点 | 仅「站点管理」添加、编辑、测试与查看账户统计；设置不重复提供站点入口 |
| 下载器 | 「设置 → 系统」卡片配置 qBittorrent / Transmission；编辑草稿后统一保存，支持启用、默认、排序；无路径映射字段 |
| 目录 | 「设置 → 目录」全局有序规则，资源目录 → 媒体库目录；不关联下载器，不选择飞牛 GUID；同一路径按首条匹配规则处理 |
| 资源下载 | 选择下载器与保存目录即可开始；默认/自动可为空；TMDB 身份为高级可选项；不要求先选影视、选择集号或二次材料确认 |
| 下载管理 | 按下载器页签读取其全部任务，可暂停、恢复与删除任务；删除下载任务保留文件 |
| 订阅 | 电视剧按季订阅，设置起始集、总集数、关键词、站点、下载器与保存目录；默认位置到实际提交下载时解析 |
| 日历 | 月、周、日程；周一开始，点击事件先看详情，再编辑；自定义周期保留已批准的设计 |
| 手动整理 | 从文件管理选择文件/目录，身份、目的目录与方式可自动；预览可选，直接开始或排队；智能重命名、刮削、媒体类型子目录实际控制文件结果 |
| 整理历史 | 单项/批量重新整理、删除历史；默认只隐藏历史记录，删除源/目标需独立选择，执行前核对文件归属与做种状态 |
| 飞牛 | 使用服务中已有媒体库的物理路径自动匹配；不在设置中绑定绝对路径与库 GUID |

未匹配自动整理规则的手动下载停留在保存目录。启用监听前已存在的文件默认只建立基线，避免升级时批量处理旧目录。保留旧加密目录快照以兼容既有任务；无关设置保存不会重写这些快照。

- 完整 `go test ./...`、生产纯 Go SQLite 的 `CGO_ENABLED=0 go test -tags modernconly ./...`、`go vet ./...` 通过。
- `go test -race ./internal/app ./internal/download` 通过；新增失败后重新下载、提交前库目录重叠复核、失效连接仍可暂停订阅等定向回归通过。
- 前端类型检查、38 项测试和生产构建通过。
- 下载协议回放验证无影视身份下载、实际保存路径、重复提交、连接中断后的幂等恢复，以及外部任务控制保留文件；未借验收向真实站点提交新下载。
- 关键词资源搜索实际执行大小、做种数、免费、分辨率、编码、包含/排除等规则，筛选与排序同时作用于渐进及最终结果；未选择影视身份不会对每条结果显示身份核对提示。
- 目录监控回放验证 native TMDB 辅助识别、NFO 冲突、规则优先级、停用下载器、容器物理路径别名与不完整文件保护。
- 整理组合验证电影/电视剧 × 重命名 × 刮削 × 类型目录；历史删除回归覆盖源/目标选择、资产替换、做种保护和中断恢复。
- 浏览器在独立本机实例实际验证下载器草稿保存/清理、目录浏览、跨页签草稿、订阅字段持久化及日历事件详情。
- 浏览器实际整理本轮独占的合成视频：自动读取 NFO 的 TMDB 603 身份，点击「开始整理」后历史成功；源文件保留，与目标 inode 相同，目标产生正确 NFO、海报和背景图。
- 精确秘密扫描覆盖 314 个候选文件，18 个已知凭据值零匹配。工作凭据、临时数据库与种子不纳入 Git。

完整应用 72 小时混合负载尚未验证；P1 插件、辅种、转移做种仍不包含。原版的全部高级分类、剧集组与任意命名模板不在本轮复制范围。
