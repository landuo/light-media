迁入插件的执行交接保护

范围：IYUUAutoSeed、SeedRescue、TorrentTransfer、TorrentTransfermusic 四个已审查的原版迁移实例。此开发改动未部署；生产仍为 v0.4.8，正式完成 7/23。全部 23 项仍须完成相同业务及各自配置、数据、文件、引用和实际交付，不能把本次保护计为新增迁移。

已迁入的配置、历史和引用不证明原执行器已停止。缺少交接记录时，保存并启用、入队、定时触发、认领及已认领任务的宿主调用会受阻；待执行任务保留原 ID。等待交接的任务不会阻塞其他新建原生实例。原生新建及明确重置后的原生选择沿用现有流程，本次没有新增日常确认页或路径映射设置。

目标应用用自身密钥加密并认证交接记录，绑定实例、来源指纹、最终导入收据摘要和导入时间。输入必须明确提供八项非 null 字段：container_id、image_sha256、finished_at、observed_at、restart_policy、running、restarting、pid。只接受已核对的原容器，且未运行、未重启、PID 为 0、重启策略为 no；观察须在两分钟内。原容器停止时间晚于目标导入时拒绝放行。这个时间比较只能排除明确过早的导入，不能证明导入内容来自停止后的读取。

Go 离线工具：cmd/plugin-handoff-owned。
--observe-source 在原 NAS 主机读取固定容器的指定 Docker 字段。它不读取环境变量、启动参数、挂载列表或健康日志；原版仍运行时非成功退出，stdout 为空，不生成可用交接数据。
--instance-id <上述原实例> --validate 只校验 stdin，不打开目标数据库。
--instance-id <上述原实例> --target-data-dir <停止的目标目录> 做只读核对。
添加 --apply 只保存目标交接记录，不启用、初始化或执行插件。目标锁、数据库状态及完整引用须通过核验；运行中的目标不能导入。普通 HTTP、表单和工作器均无创建交接记录的能力，目标服务无须 Docker socket。

来源观察由已有授权 SSH 主机上的可信交付器执行；stdin JSON 是受信任的本地管理员输入，不是远程证明。正式切换必须在完整 23 项具备交付条件后进行：原容器真正停止并关闭自动重启，再重新只读采集并核对最终配置、运行数据和文件，完成目标导入，最后核验交接。当前固定的数据摘要若已变化，须重新审查和验证，不能忽略不匹配或沿用旧快照。原版 SeedRescue.stop_service 最多等待扫描线程十秒，关闭启用开关或 HTTP 200 均不足以证明退出。

新程序启用后原容器须持续停止。回切须先停止新侧写任务并核对未完成操作。本次未实现自动回切或撤销 CLI，也未授权或执行原容器停止、重启策略修改、原配置修改。四个真实实例均未签发交接，生产未导入新增实例。

验证分开计证：实际原配置/数据只经内存和 stdin 进入独占加密测试库；执行前站点、下载器及目录全部替换为独占夹具，停止状态也是合成观察。原数据测试的普通及竞态检查覆盖 IYUU 12 项、SeedRescue 22 项、两份转移插件合计 40 项（均含子测试）；不表示联系了用户站点或操作了原种子。NAS 的 1 核、512 MiB、network=none 容器只覆盖两份转移插件的 40 项及真实离线 CLI。另在 NAS 只读观察了仍运行的原版，确实拒绝放行且 stdout 为空；真实交接数为 0。独占容器和目录已移除，并独立核对生产二进制、compose 和既有容器身份未改。

汇总竞态检查的整套 600 秒超时记录保留，不能算通过。最终分组结果、相同用例全集、冻结输入、构建状态和秘密扫描以 plugin-execution-handoff-verification.json 为准。前端及版本未改；本次没有新的浏览器验收，先前插件界面的独占证据仍独立计证。
