# 输入控件与原版样式对齐（v0.4.10）

2026-10-23，按用户要求统一表单输入控件，已部署到 NAS 的 3120 服务。

## 改动

- 设置、站点、订阅、手动整理、目录规则、下载确认、资源筛选、日期周期、登录等表单使用现有 Vuetify 3.7.3 的 VTextField、VSelect、VTextarea 和 VCombobox。沿用原版 outlined 样式、浮动标签、紫色聚焦边框及同系列字段图标。
- 常规字段高度 56px，工具栏下拉框使用 40px 紧凑尺寸，统一 8px 圆角及提示文字间距。下拉框不再被同行字段的提示内容撑高。
- 原生输入样式排除 Vuetify 内部节点，避免额外边框、字号、背景和内边距冲突；补齐边框伪元素的盒模型，消除浮动标签缺口处的像素错位。
- 下载目录既可从已有目录选择，也可直接输入；手动整理目的路径继续独立编辑、清空和打开目录选择器。删除此次替换后已无引用的 SubscriptionField 手工样式组件。
- 保留专用的全局搜索框、文件过滤栏、站点多选与复选开关等已有交互。本次没有重做页面布局或增加业务步骤。

参照本机只读 MoviePilot-Frontend 的 `src/plugins/vuetify/defaults.ts`、`src/styles/common.scss`、`src/@core/scss/libs/vuetify/_overrides.scss` 和 `src/components/dialog/SiteAddEditDialog.vue`；未修改原项目。

## 验证

- 工作树前端 176 项回归测试通过；生产基线前端 172 项测试通过；两者类型检查和 Vite 构建通过。测试中的组件替身更新为实际使用的 Vuetify 控件，保留对请求内容、状态及失败行为的断言。
- Chrome 独立合成环境：站点弹窗输入、聚焦与下拉；订阅开始集数改为 5、进阶包含规则改为 2160p 后提交，捕获请求确认值和数字类型正确；目录规则可展开、可从路径字段打开目录选择；手动整理选择硬链接后两次预览分别使用当前输入的 `/library/custom` 和 `/library/revised`；下载确认手动输入 `/downloads/custom` 后选择 Transmission，捕获请求确认下载器为 `tr` 且目录未被重置。测试服务只记录请求，不连接真实站点、下载器或媒体目录。
- NAS 实机：更新后读取设置页与站点新增弹窗，7 个单行字段实测均为 56px 高、8px 圆角，文本域为 104px 高；焦点浮动标签和边框显示正常，浏览器未记录警告或错误。检查后关闭空白新增弹窗，未保存配置。此次未单独做手机视口实测。
- Linux amd64、CGO=0、modernconly 编译和 web 嵌入资源测试通过；NAS 独占临时容器以只读根目录、无网络、普通用户、256 MiB / 0.5 CPU 启动，健康、初始化及前端版本检查通过，随后清理。

## 发布

发布源在 v0.4.9 实际生产源（原基线 `110ffc7b22755b53accaa3992ab2eb5c79ab91f3` 加搜索页修正）上应用本轮 UI 改动。Settings、SiteManager 及对应测试保留生产基线的业务实现，未引入工作树已有但未发布的站点消息功能。后端文件比对仅版本常量变化。

只更新 light-media 二进制并重建该容器。设置、插件配置、安装状态、密钥和 hosts 校验一致，正式迁移收据仍为 7。原 MoviePilot 和 qBittorrent 的进程、启动时间及运行状态保持一致。旧二进制保留在独占发布目录中，可仅回退程序而不覆盖数据。
