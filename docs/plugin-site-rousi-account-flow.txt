采集行为
API Key 仅以 Bearer 头请求 /api/v1/profile?include_fields[user]=seeding_leeching_data；不发送站点 Cookie 或消息 Token。支持身份、等级回退、注册时间、上传/下载/魔力、分享率的原版二位舍入及做种/下载中的数量和体积。源 DTO 默认零值与本地“未观测到”空值分别保存。资料接口接受原版 200/403/500 JSON 分支，其他状态、非法 JSON、业务错误和解析异常分别沿用原版默认 DTO、错误 DTO 或无 DTO 的结果；本地连接健康状态独立报告。

站点 Token 单独用于 /api/messages 的 page=0、page_size=100、unread_only=true 查询；保留已有 Bearer 前缀、消息顺序、重复项和空字段。即使零条消息，原版仍 POST /api/messages/read-all，并忽略该 POST 的响应；Go 实现保留此行为。原版将 DTO 字段校验放在采集后，因而部分无效身份数据会在消息请求完成后才失败；对照样本也覆盖此顺序。

每次请求前继续检查配置、授权、任务取消和访问额度。修改 Token 会改变连接标识并阻止旧在途请求继续标记已读。每请求 60 秒，保留 8 MiB 响应/累计消息、50 页和 10,000 条消息上限；限额或撤销产生失败，不提交不完整源 DTO。浮点页数按原比较循环处理，字符串页数保持解析失败。

原生接入
网址识别肉丝专用适配，导入兼容原 MoviePilot 的 apikey/token；www 地址规范到已确认主站。API Key 与消息 Token 独立加密保存，普通站点查询仅返回凭据状态。编辑肉丝默认打开 API 页签，Authorization 使用密码输入框，留空继续保留原配置；Token 不成为公共资源、日志或客户端 Config JSON 的内容。
原生搜索请求 /api/v1/torrents，使用一基页码、page_size=100 和原关键词；转换标题、副标题、体积、人数、发布日期和原版生效促销倍率。下载先以 API Key 查询 /api/v1/torrents/:id，再取 data.download_url；种子内容请求不携带 API Key、Token 或 Cookie，并验证实际 metainfo。
