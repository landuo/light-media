## Transport, ownership and non-expansion

The only controller is literal `http://127.0.0.1:39123`; every call validates scheme/netloc/hostname/port/path/no userinfo/query/fragment and held child PID/starttime/executable/listener inode. It uses the accepted exact http.client controller, not a generic proxy-disabled opener; redirects and arbitrary destinations are refused. Any request/permission/transport failure ends this route, with no alternate transport or retry. Registration polling is only original allowed 404→405 readiness; it never retries denied or transport-failed calls.

The owned peer binds AF_INET `127.0.0.1:0` once before bootstrap/normal server creation, with no IPv6 or alternative-route fallback. Only GET /index,/worker,/api/v2/app/webapiVersion,/api/v2/app/cookies and POST /api/v2/auth/login,/api/v2/app/setCookies,/api/v2/torrents/add exist. It has no request client/upstream/forward/CONNECT implementation. The literal `.invalid` torrent URL is a passive payload value and is never fetched. Credentials/session are synthetic and generated in memory. No netrc, real credentials, DB reads, media, NAS, daemon or file deletion.

ENV is inherited unchanged after the explicit coordinator marker; no proxy/CA/hosts/system/product proxy edits, no direct fallback. Normal bootstrap uses only owned settings (statistics off, server URL empty, no sites/roots, one enabled shared-path qB configuration); the no-environment-change claim is not a claim that the owned bootstrap settings were left default. No new global TLS permission: native's already accepted qB-only transport applies.

Eighteen old S03 helper ASTs and the final cleanup block are inherited exactly; `helper-reuse.json` binds both drivers. Actual children only, natural SIGTERM→Wait0 required. Forced cleanup marks FAIL and uses only held child/PID-starttime identities. All run evidence remains in a new exclusive `test-instances/s03-qb-cookie-*`; nothing is deleted. Login response headers/body and bootstrap secret body are not retained. Host logs/private DB remain private evidence, not a publication whitelist.
